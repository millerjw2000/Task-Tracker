# Task Tracker

This project is a basic Task tracker that lets the user create, delete, and change the status of tasks. 
The backend is built with spring-boot and the frontend is built with react. 

The app hosted on AWS with through their Elastic Container Service. It is currently available at: http://frontend-alb-127162849.us-east-1.elb.amazonaws.com/
** AS OF 2/20 THE APP IS NO LONGER BEING HOSTED PUBLICLY **

# Tech used
- Front end
  - React
  - React-router-dom
  - axios
  - CSS
- Back end
  - Spring
  - JWT authentication
  - PostgreSQL

- Task page containing all of the user's tasks. They can create a new task using the form in the upper left. They can view their active tasks below under the 'Your Tasks' section. There the tasks are sorted into three categories: Upcoming, Overdue, and Completed. A task can be moved back and forth from completed using the checkbox next to it. After the date on a task has passed, if it has not been marked completed, it will be moved to the overdue section. Tasks can be deleted using the X button next to them.
